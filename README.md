# 🟨 Microsoft Power BI for Business Intelligence

---

# 📖 Sobre o Projeto

Este repositório reúne minha jornada de aprendizado em **Microsoft Power BI**, com foco em **Business Intelligence**, modelagem de dados, visualização de informações e desenvolvimento de dashboards interativos para apoio à tomada de decisão.

Os projetos foram organizados de forma progressiva, abrangendo desde os fundamentos da ferramenta até técnicas avançadas utilizando **Power Query**, **Linguagem M**, **DAX**, **R** e **Python**.

Cada projeto representa uma aplicação prática dos conhecimentos adquiridos durante o curso, utilizando cenários reais de negócio para desenvolver soluções analíticas e profissionais.

---

# 🎯 Objetivos

- Desenvolver dashboards profissionais no Microsoft Power BI
- Aplicar processos de ETL utilizando Power Query
- Construir modelos relacionais eficientes
- Desenvolver métricas e indicadores utilizando DAX
- Automatizar transformações de dados com Linguagem M
- Integrar análises utilizando R e Python
- Desenvolver soluções de Business Intelligence para apoio à tomada de decisão
- Construir um portfólio profissional de projetos
