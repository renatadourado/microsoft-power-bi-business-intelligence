# Análise financeira

## Objetivo

Desenvolver um dashboard financeiro com indicadores, estruturação de dados e análises gerenciais.

## Competências desenvolvidas

- KPIs financeiros
- Análise gerencial
- Tratamento de dados
- Dashboard financeiro

## Estrutura dos arquivos

### `dashboards/`

- `dashboard-de-analise-financeira.pbix`

### `dados/`

- `dadosfinanceiros.xlsx`

### `documentacao/`

- `quais-sao-os-principais-kpis-da-area-de-financas.pdf`

### `scripts/`

- `pivot.txt`

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
