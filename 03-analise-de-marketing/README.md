# Análise de marketing

## Objetivo

Analisar clientes, campanhas, comportamento de compra e desempenho dos pontos de venda.

## Competências desenvolvidas

- Análise de clientes
- Campanhas de marketing
- Segmentação
- Storytelling com dados

## Estrutura dos arquivos

### `dashboards/`

- `analise-de-campanhas-de-marketing-visaocliente.pbix`
- `analise-de-campanhas-de-marketing-visao-comportamento-de-compra-do-cliente.pbix`
- `analise-de-campanhas-de-marketing-visao-da-performance-das-campanhas-de-marketing.pbix`
- `analise-de-campanhas-de-marketing-visao-dos-padroes-de-compra-por-ponto-de-venda.pbix`

### `dados/`

- `dados-marketing.csv`

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
