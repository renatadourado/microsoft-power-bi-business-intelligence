# Análise logística

## Objetivo

Avaliar operações logísticas por meio de KPIs, visualizações e comparações.

## Competências desenvolvidas

- KPIs logísticos
- Análise operacional
- Monitoramento de desempenho
- Dashboards

## Estrutura dos arquivos

### `dashboards/`

- `analise-de-dados-de-logistica-parte1.pbix`
- `analise-de-dados-de-logistica-parte2.pbix`

### `dados/`

- `dataset.xlsx`

### `documentacao/`

- `quais-sao-os-principais-kpis-da-area-de-logistica.pdf`

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
