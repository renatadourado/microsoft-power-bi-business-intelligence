# Análise contábil

## Objetivo

Representar informações contábeis e construir um balanço patrimonial com visual de matriz.

## Competências desenvolvidas

- Balanço patrimonial
- Visual de matriz
- Estrutura contábil
- Relatórios gerenciais

## Estrutura dos arquivos

### `dashboards/`

- `balanco-patrimonial-com-visual-de-matriz.pbix`

### `dados/`

- `dataset.xlsx`

### `documentacao/`

- `o-que-e-um-balanco-patrimonial.pdf`
- `os-principais-relatorios-em-ciencias-contabeis.pdf`

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
