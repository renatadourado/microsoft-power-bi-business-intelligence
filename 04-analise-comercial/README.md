# Análise comercial

## Objetivo

Construir indicadores comerciais e acompanhar desempenho de vendas e resultados.

## Competências desenvolvidas

- KPIs comerciais
- Análise de vendas
- Indicadores de desempenho
- Tomada de decisão

## Estrutura dos arquivos

### `dashboards/`

- `dashboard-comercial.pbix`

### `dados/`

- `dados-comerciais.xlsx`

### `documentacao/`

- `mp2.pdf`
- `o-que-representa-a-area-comercial-para-uma-empresa.pdf`
- `quais-sao-os-principais-kpis-da-area-comercial.pdf`

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
