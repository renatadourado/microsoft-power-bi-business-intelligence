# Análise do mercado de ações

## Objetivo

Interpretar dados do mercado financeiro e criar uma narrativa analítica no Power BI.

## Competências desenvolvidas

- Mercado financeiro
- Narrativa inteligente
- Séries históricas
- Análise de desempenho

## Estrutura dos arquivos

### `dashboards/`

- `dashboard-analitico-do-mercado-de-acoes-com-narrativa-inteligente.pbix`

### `dados/`

- `stockmarket.xlsx`

### `documentacao/`

- `interpretando-dados-do-mercado-de-acoes.pdf`

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
