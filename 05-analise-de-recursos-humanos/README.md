# Análise de Recursos Humanos

## Objetivo

Explorar indicadores de pessoas e apoiar decisões da área de Recursos Humanos.

## Competências desenvolvidas

- People Analytics
- KPIs de RH
- Análise exploratória
- Visualização de dados

## Como utilizar

1. Leia a documentação disponível no módulo.
2. Abra os arquivos de dados para compreender a origem das informações.
3. Abra o arquivo `.pbix` no Power BI Desktop.
4. Verifique as etapas do Power Query, o modelo de dados, as medidas e as visualizações.
5. Registre melhorias e aprendizados no histórico de commits.
